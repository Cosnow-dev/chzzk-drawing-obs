치지직 드로잉 (스트리머 화면에 그리기)

* 참고: 시청자는 [치지직 드로잉 확장 프로그램](https://github.com/Cosnow-dev/chzzk-drawing-chrome-extension)을 사용해서 방송 송출 화면에 그림을 그릴 수 있습니다.

OBS 설정 방법!
1. Code>Download Zip으로 파일을 받고 압축을 풉니다.
2. *매우 중요!* 메모장으로 obs.html을 엽니다.
   const MY_CHANNEL_ID = '여기에_본인_아이디를_넣으세요'; 부분을 찾습니다.
   '여기에_본인_아이디를_넣으세요' 를 본인 치지직 라이브 링크의 뒷부분 문자열을 넣습니다.
   https://chzzk.naver.com/live/abcd1234라면 'abcd1234'; 이렇게 바꾸면 됩니다. (따옴표와 세미콜론 유지에 주의)
3. OBS에서 "브라우저"를 추가합니다.
4. "로컬 파일" 체크하고 찾아보기로, 압축을 푼 obs.html을 불러옵니다.
5. 너비와 높이는 방송 송출화면과 동일해야합니다. 만약 1920x1080으로 송출하신다면 그대로 너비와 높이를 설정해주세요.
6. 확인을 누르고, 브라우저 송출이 송출 화면 크기와 동일한지 체크해주세요.
7. 완료 되었습니다! 시청자들의 손그림과 함께 알차고 즐거운 방송 되세요!
